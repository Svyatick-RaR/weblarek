# Интернет-магазин «Web-Larёk»

«Web-Larёk» — это интернет-магазин с товарами для веб-разработчиков. Пользователи могут просматривать каталог, добавлять товары в корзину и оформлять заказы. Приложение получает каталог с сервера и отправляет данные заказов через API.

## Архитектура приложения

Код приложения организован согласно архитектурному подходу MVP (Model-View-Presenter), который разделяет ответственность между основными слоями:

- **Model** — слой данных, отвечает за хранение и изменение данных.
- **View** — слой представления, отвечает за отображение информации и взаимодействие с пользователем.
- **Presenter** — связывает модели и представления, обрабатывает события и управляет логикой приложения.

Для взаимодействия между компонентами используется событийно-ориентированный подход. Брокер событий `EventEmitter` реализует паттерн «Наблюдатель» и обеспечивает обмен событиями между частями приложения.

## Базовый код

### Класс Component

Базовый класс для компонентов интерфейса. Является дженериком и принимает тип данных `T`, которые могут передаваться в метод `render`.

**Конструктор:**

- `constructor(container: HTMLElement)` — принимает DOM-элемент, за отображение которого отвечает компонент.

**Поля:**

- `container: HTMLElement` — корневой DOM-элемент компонента.

**Методы:**

- `render(data?: Partial<T>): HTMLElement` — принимает данные, записывает их в поля компонента и возвращает DOM-элемент.
- `setImage(element: HTMLImageElement, src: string, alt?: string): void` — устанавливает изображение и альтернативный текст для элемента `<img>`.

### Класс Api

Содержит базовую логику отправки HTTP-запросов.

**Конструктор:**

- `constructor(baseUrl: string, options: RequestInit = {})` — принимает базовый адрес сервера и дополнительные настройки запросов.

**Поля:**

- `baseUrl: string` — базовый адрес сервера.
- `options: RequestInit` — настройки HTTP-запросов.

**Методы:**

- `get(uri: string)` — выполняет GET-запрос и возвращает Promise с ответом сервера.
- `post(uri: string, data: object, method: ApiPostMethods = 'POST')` — отправляет данные в формате JSON. Поддерживает методы POST, PUT и DELETE.
- `handleResponse(response: Response)` — обрабатывает ответ сервера: возвращает данные при успешном запросе или отклоняет Promise при ошибке.

### Класс EventEmitter

Брокер событий, реализующий паттерн «Наблюдатель». Позволяет подписываться на события и инициировать их.

**Поля:**

- `_events` — коллекция событий и соответствующих обработчиков.

**Методы:**

- `on(event, callback)` — подписывает обработчик на событие.
- `off(event, callback)` — отменяет подписку.
- `emit(event, data?)` — инициирует событие и передаёт данные обработчикам.
- `onAll(callback)` — подписывает обработчик на все события.
- `offAll()` — удаляет все подписки.
- `trigger(event, context?)` — создаёт функцию для инициирования события с заданным контекстом.

## Модели данных

Модели отвечают за хранение и изменение данных приложения. Они не зависят от DOM и не выполняют HTTP-запросы.

### Класс Products

Отвечает за хранение каталога товаров и выбранного товара.

**Поля:**

- `products: IProduct[]` — список товаров.
- `selectedProduct: IProduct | null` — выбранный товар.

**Методы:**

- `setProducts(products)` — сохраняет список товаров.
- `getProducts()` — возвращает список товаров.
- `getProductById(id)` — находит товар по идентификатору.
- `setSelectedProduct(product)` — сохраняет выбранный товар.
- `getSelectedProduct()` — возвращает выбранный товар.

### Класс Basket

Отвечает за управление корзиной покупок.

**Поле:**

- `items: IProduct[]` — список товаров в корзине.

**Методы:**

- `getItems()` — возвращает товары в корзине.
- `addItem(product)` — добавляет товар, если его ещё нет в корзине.
- `removeItem(id)` — удаляет товар по идентификатору.
- `clear()` — очищает корзину.
- `getTotal()` — рассчитывает общую стоимость товаров.
- `getCount()` — возвращает количество товаров.
- `hasItem(id)` — проверяет наличие товара в корзине.

### Класс Buyer

Отвечает за хранение и проверку данных покупателя.

**Поле:**

- `buyer: IBuyer` — данные покупателя: способ оплаты, email, телефон и адрес.

**Методы:**

- `setBuyer(data)` — обновляет данные покупателя.
- `getBuyer()` — возвращает данные покупателя.
- `clear()` — сбрасывает данные покупателя.
- `validate()` — проверяет заполненность обязательных полей и возвращает ошибки.

## Взаимодействие с API

### Класс ApiClient

Класс обеспечивает взаимодействие приложения с сервером, используя базовый класс `Api`.

**Конструктор:**

- `constructor(api: IApi)` — принимает экземпляр API-клиента.

**Методы:**

- `getProducts()` — получает каталог товаров с сервера (`GET /product/`).
- `createOrder(order)` — отправляет данные заказа на сервер (`POST /order`).

### Настройка API

Адрес сервера задаётся в файле `.env`:

```env
VITE_API_ORIGIN=https://larek.ffapi.ru
```

В `src/utils/constants.ts` формируется базовый адрес API:

```ts
export const API_URL = `${import.meta.env.VITE_API_ORIGIN}/api/weblarek`;
```

## Типы данных

В файле `src/types/index.ts` определены основные типы и интерфейсы приложения:

- `IProduct` — структура товара.
- `IBuyer` — данные покупателя.
- `TPayment` — доступные способы оплаты (`card` и `cash`).
- `IProductsResponse` — ответ сервера с каталогом товаров.
- `IOrderRequest` — данные для отправки заказа.
- `IOrderResponse` — ответ сервера после оформления заказа.
- `IApi` — интерфейс для работы с API.

## Точка входа приложения

В файле `src/main.ts` создаются экземпляры моделей и API-клиента. Здесь выполняется проверка методов моделей, отправляется запрос на получение каталога, а полученные товары сохраняются в модели `Products`.
